# NFR-007 Modular API (M)

Spec: [requirements.md, NFR-007](../../specs/CHG-0001/requirements.md#nfr-007-modular-api-m) (constraint C-2).

**Acceptance criteria in brief.** AC-1 one application, one process, one SQLite file, one pool; AC-2 a test fails for cross-module
use of unpublished types or for a dependency cycle; AC-3 identity and to-dos modules exist and every contract operation belongs to exactly one.

**Implemented by.** [identity module](../components/identity-module.md), [to-dos module](../components/todos-module.md),
[shared kernel](../components/shared-kernel.md), [composition root](../components/composition-root.md); the seam `app.todo.auth.api.CurrentUser`;
[ADR-0018](../decisions/adr-0018-modular-monolith-module-boundaries.md).

**Verified by.** [architecture tests](../tests/architecture-tests.md) (`ArchitectureTest`, `ArchitectureNonVacuityTest`),
[contract tests](../tests/contract-tests.md) (`EndpointInventoryTest`), [API integration tests](../tests/api-integration-tests.md) (`ModuleWiringTest`).
