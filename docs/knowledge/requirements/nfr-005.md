# NFR-005 Technology stack (M)

Spec: [requirements.md, NFR-005](../../specs/CHG-0001/requirements.md#nfr-005-technology-stack-m).

**Acceptance criteria in brief.** AC-1 React and TypeScript UI, Spring Boot API, HTTP between them, SQLite storage.

**Implemented by.** [web SPA](../components/web-spa.md) (`web/package.json`), [identity module](../components/identity-module.md) and
[to-dos module](../components/todos-module.md) on Spring Boot 4.1.2 (`api/pom.xml`), SQLite via `sqlite-jdbc` ([schema](../data/schema.md)).
Decisions: [ADR-0001](../decisions/adr-0001-react-typescript-spa.md), [ADR-0002](../decisions/adr-0002-spring-boot-rest-api.md), [ADR-0003](../decisions/adr-0003-sqlite-persistence.md).

**Verified by.** Review of `web/package.json` and `api/pom.xml`; [e2e tests](../tests/e2e-tests.md) exercise the browser-to-API path.
