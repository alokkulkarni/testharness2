# NFR-006 User-friendly error messages (M)

Spec: [requirements.md, NFR-006](../../specs/CHG-0001/requirements.md#nfr-006-user-friendly-error-messages-m).

**Acceptance criteria in brief.** AC-1 every failure says what went wrong and gives a next step; AC-2 no stack trace, class name,
SQL, error code, request id, response body or browser error text is shown; AC-3 an unexpected render error shows a recoverable
page; AC-4 wrong password and unknown identifier give identical messages.

**Implemented by.** [web SPA](../components/web-spa.md): `web/src/errors/userMessage.ts` (`userMessageFor`, the single source of copy),
`web/src/app/AppErrorBoundary.tsx`, `web/src/api/client.ts` (turns each failed call into a `Failure`). The failure table is
[sdd.md section 6.1](../../specs/CHG-0001/sdd.md#61-spa-error-presentation-nfr-006).

**Verified by.** [web unit tests](../tests/web-unit-tests.md) (`userMessage.test.ts`), [web component tests](../tests/web-component-tests.md) (`errors.test.tsx`),
[e2e tests](../tests/e2e-tests.md) (`states.spec.ts`).

**Decisions.** [ADR-0011](../decisions/adr-0011-problem-details-error-model.md).
