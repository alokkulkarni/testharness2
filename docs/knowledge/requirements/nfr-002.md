# NFR-002 Run locally (M)

Spec: [requirements.md, NFR-002](../../specs/CHG-0001/requirements.md#nfr-002-run-locally-m).

**Acceptance criteria in brief.** AC-1 the UI and API are usable on a developer machine with no cloud or hosted service;
AC-2 no `dev` or `test` deployment is required.

**Status: AC-1 deferred, not met at HEAD.** The frozen [sdd.md section 11](../../specs/CHG-0001/sdd.md#11-local-run-nfr-002-req-data-001-ac-3)
requires `.env.example` (with `TODO_DB_PATH`, `TODO_COOKIE_SECURE=false`, `SERVER_PORT=8080`) and README run steps. Neither file
has the required content at HEAD (finding F-14 in the N12 verdict). The requester deferred this to a follow-up change, and the
debt owner and due date are an assumption to confirm on the PR (finding F-20). The runtime path is evidenced: the Playwright main
configuration starts the API and SPA with the section 11 commands on localhost (`web/e2e/support/launch.ts`, `web/e2e/support/api-process.ts`).

**Implemented by.** Local-only configuration: [composition root](../components/composition-root.md) (`DatabaseConfig`), `api/src/main/resources/application.properties`,
`web/vite.config.ts` (proxy to `localhost:8080`).

**Verified by.** [e2e tests](../tests/e2e-tests.md) (`network.spec.ts`, which checks that the browser talks only to localhost).
