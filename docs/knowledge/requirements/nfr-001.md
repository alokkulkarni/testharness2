# NFR-001 Accessibility (M)

Spec: [requirements.md, NFR-001](../../specs/CHG-0001/requirements.md#nfr-001-accessibility-m).

**Acceptance criteria in brief.** AC-1 no WCAG 2.1 AA failure on six screens; AC-2 every action reachable by keyboard with
visible focus and dialog focus handling; AC-3 field errors associated with their field and announced.

**Note (Q36).** The 8-hour session with no warning is recorded as met under WCAG 2.2.1's "essential" exception, not as a failure.

**Implemented by.** [web SPA](../components/web-spa.md) (`usePageFocus.ts`, `ConfirmDialog.tsx`, `ui.tsx`, the `aria-describedby` error pattern),
[sdd.md section 9](../../specs/CHG-0001/sdd.md#9-accessibility-nfr-001).

**Verified by (automated checks only).** [accessibility tests](../tests/accessibility-tests.md) (axe, keyboard scripts), [web component tests](../tests/web-component-tests.md) (`a11y.test.tsx`).

**Not recorded (open gap).** [sdd.md section 14](../../specs/CHG-0001/sdd.md#14-verification-and-traceability), in its NFR-001 row, calls for a manual
screen-reader and contrast pass on eight screens, recorded by web-qa, and REQ-NAV-001 AC-6 calls for a flash review of the
not-found animation. Neither check is recorded in the CHG-0001 evidence: the evidence holds lint, typecheck and lint-contracts
outputs, and the N10 plan (`docs/specs/CHG-0001/plan/N10-build-react.md`) records neither. This bundle does not state that either
check was done. Whether it was done outside the recorded evidence is not known.

**Gaps.** Firefox end-to-end runs did not launch on the build host, so the accessibility runs cover chromium and webkit only
(`.harness/changes/CHG-0001/verdicts/N12-validate.validator.json`, F-9 and F-19).
