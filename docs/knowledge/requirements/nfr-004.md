# NFR-004 Security baseline (M)

Spec: [requirements.md, NFR-004](../../specs/CHG-0001/requirements.md#nfr-004-security-baseline-m).

**Acceptance criteria in brief.** AC-1 strong salted password hashing ([REQ-AUTH-003](req-auth-003.md)); AC-2 server-side validation and no
stack traces or SQL in responses; AC-3 no secrets or real credentials committed.

**Implemented by.** [identity module](../components/identity-module.md) (`PasswordHasher`), [shared kernel](../components/shared-kernel.md) (`ProblemDetailsAdvice`,
`ProblemWriter`), [common problem model](../apis/common-problem-model.md), [ADR-0005](../decisions/adr-0005-argon2id-password-hashing.md),
[ADR-0011](../decisions/adr-0011-problem-details-error-model.md). The BouncyCastle library is at 1.85 for two CVEs (`api/pom.xml`; finding F-12).

**Verified by.** AC-2 is tested: [API integration tests](../tests/api-integration-tests.md) (`ErrorSourcesTest`, `HandlerExceptionTest`,
`FilterExceptionTest`), [contract tests](../tests/contract-tests.md). AC-1 is inspected (`api/src/main/java/app/todo/auth/PasswordHasher.java:L6-L14`),
with `PasswordStorageTest` as supporting evidence. AC-3 is inspected: the secret scan and security review are in the N11 security verdict
(`.harness/changes/CHG-0001/verdicts/N11-security.security.json`). The [conformance register](../../specs/CHG-0001/conformance.md) marks the
NFR-004 row and AC-1 and AC-3 as inspected, not tested. Logging rules: [shared kernel](../components/shared-kernel.md#logging-rules).
